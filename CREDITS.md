# HoloCraft credits

HoloCraft by Zandy (MIT for HoloCraft's own code and sheets).

Played through the player's own copies of:
- **HoloCure - Save the Fans!** by Kay Yu, a free fan game of hololive production (cover corp.). HoloCraft ships none of
  its files: on first start it reads the player's installed HoloCure and builds the sprites, music, sounds and fonts
  into a resource pack on that PC only.
- **Minecraft: Java Edition** by Mojang Studios. The player signs in with their own account.

Bundled, each under its own licence:
- Prism Launcher 11.1.1 (GPL-3.0) - https://prismlauncher.org
- Fabric Loader and Fabric API (Apache-2.0) - https://fabricmc.net
- e4mc 6.2.3 by skyevg (MIT) - https://e4mc.link - carries co-op games over the internet
- Apache Commons Compress / IO / Lang (Apache-2.0), inside holocraft.jar

hololive, HoloCure and their characters belong to their owners. HoloCraft is an unofficial fan mashup.
